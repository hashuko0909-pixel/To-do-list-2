# To Do List App

A simple To Do List application source project.

Features:
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks complete
- High priority
- Material 3 interface

Build an Android APK after the Android project files are generated:

```bash
flutter create --platforms=android .
flutter pub get
flutter build apk --release
```

APK output:
`build/app/outputs/flutter-apk/app-release.apk`
